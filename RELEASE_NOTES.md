## OnkyoMac 1.2 — V1 complete

The polished, complete V1 of OnkyoMac: native Onkyo/Integra receiver control living in
your menu bar.

**Highlights**
- ⚡ Power on/off from network standby, with state re-read across the boot window
- 🎚️ Capsule volume bar with damped swipe-to-adjust and mute on the glyph
- 🎛️ Inputs shown with the receiver's own labels (STRM BOX, renames — any model)
- 📺 HDMI output routing: Main / Sub / Main + Sub
- 🎵 Now Playing with album art and transport for Network/Bluetooth/USB
- 🔊 Sound modes + a subtle codec → mode → channels readout
- ⚡ Real-time push updates, instant panel, zero background cost, no cloud, no dependencies

**Install:** download `OnkyoMac.dmg` below, drag to Applications, launch.
First launch: macOS will warn that the app isn't notarized (it's open source, unsigned) —
go to **System Settings → Privacy & Security → Open Anyway**. Full instructions and a
one-line Terminal install that skips the dialog are in the
[README](https://github.com/inakizamores/OnkyoMac#install).

**Requires:** macOS 14+, Apple Silicon, a network-connected Onkyo/Integra (or recent
Pioneer) receiver with Network Standby enabled.
